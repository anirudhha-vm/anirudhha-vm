## 🚀 Featured Projects

### 🦾 Autonomous Pick-and-Place Pipeline — Unitree G1 Humanoid Robot
- **Tech Stack:** NVIDIA Isaac Sim 5.1, ROS 2 Jazzy, Pinocchio, Python.
- Built a closed-loop, perception-driven manipulation stack for the 29-DOF Unitree G1 humanoid with a Dex3-1 hand.
- Integrated RGB-D perception (object detection, depth reconstruction, stability-gated 3D pose estimation).
- Architected a robust 18-state FSM verification.

### 🚙 Warehouse Autonomous Mobile Robot (AMR) — LiDAR SLAM
- **Tech Stack:** NVIDIA Isaac Sim, ROS 2 Jazzy, SLAM Toolbox.
- Real-time 2D SLAM Simulation for a differential-drive warehouse AMR.
- Engineered odometry filtering, TF trees mapping, and SLAM processing with precise LaserScan registration.

- Bridged ROS 2 topics to the Isaac Sim articulation controller via OmniGraph Action Graph.
